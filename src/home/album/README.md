# 三猫小相册

- `cat-album-episodes.mjs` 是已批准公开的漫画目录，按新到旧排列；不要扫描素材源文件夹来自动补齐。
- 首页正常点击由 `cat-album.mjs` 打开原弹窗；真实链接始终指向 `cat-album.html`，脚本或弹窗不可用时仍能进入完整目录。
- `cat-album.html` 和 `pages/` 是目录的静态阅读副本。目录不放漫画大图，单篇页只加载所选的一张，且没有脚本依赖。原生图片懒加载在关闭脚本时可能失效，所以不能把整册图片放进隐藏区域当后备。
- 新漫画经确认后，更新目录、静态目录与阅读页、首页显示总数，以及 `scripts/runtime-files.mjs` 和交付文件清单。阅读页首尾循环，新增一期也要同步页码与相邻链接。
- `tests/delivery/cat-album-delivery.test.mjs` 精确核对所有页面的标题、说明、图片、顺序、总数和前后链接，防止静态副本与弹窗内容分叉；`tests/home/cat-album-ui.test.mjs` 覆盖弹窗与失败降级。

修改后运行 `npm run verify`，并实际检查正常点击、禁用脚本、脚本请求失败、手机尺寸和键盘翻阅。没有发布授权时只交付本地预览。
